# Weekly Recaps

Generated every Friday after the day's daily briefing has shipped. Each week produces:

- **`YYYY-Www.md`** — the Markdown weekly recap (auto-generated via Claude API).
- **NotebookLM audio overview** (~10 min) — generated by pasting the Markdown into [notebooklm.google.com](https://notebooklm.google.com). The share URL goes into the weekly file's `audio_overview_url:` front-matter field; optional download lives at `audio/YYYY-Www.mp3` if you want a local copy.

See [`../workflow.md`](../workflow.md) §"Weekly run" for the step-by-step.
