## Notes & Decisions

- **Overlap to monitor:** Ben's Bites, The Rundown AI, TLDR AI, Smol.ai News, and The Neuron all do "daily AI roundup". Run all five for the first two weeks, then drop the lowest-signal two based on observed redundancy.
- **Email-only handling:** Ben Evans' newsletter is email-only — set up a Kill-the-Newsletter address (or rss.app) and add the resulting feed URL here.
- **Stratechery (paid):** if you don't subscribe, drop it. Don't substitute — its angle isn't replaceable.
- **Geographic balance:** the list skews US/Anglosphere. Mistral is the only non-US frontier lab. For Tier 2/3, consider adding one Chinese-AI tracker (e.g. ChinaTalk by Jordan Schneider) and one EU policy source (e.g. EU AI Office updates) — leaving these out of v1 to keep scope tight.
- **Velocity tuning:** if total daily volume exceeds ~100 items, the editor will need stricter filters; raise the importance threshold or drop T5 first.
- **Versioning:** changes to this list should be commits with a rationale in the message — the source set is part of the pipeline's reproducibility contract.
