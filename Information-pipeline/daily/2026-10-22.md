## 📦 Products & Tooling

### Anthropic donates Agent Skills to the Agentic AI Foundation
Agent Skills, the format that lets an agent load specialised instructions from a folder containing a SKILL.md file, moves to the Agentic AI Foundation (AAIF) under the Linux Foundation, along with the name, logo, GitHub organisation and agentskills.io domain. Anthropic says engineers from Anthropic, Google, OpenAI and others will maintain it as individuals, with a roadmap of versioned releases, a formal proposal process and security guidance. It cites more than 70 platforms supporting skills, about 1 million skills published and nearly 280 million installs (Anthropic's figures).
**Why it matters (PM):** Skills are becoming a portable packaging unit for agent behaviour, so writing your product's workflows as skills is now a lower-lock-in bet than a vendor-specific plugin format.
**Why it matters (mid-market):** Mid-sized vendors can ship one skill package that works across ChatGPT, Copilot and Cursor customers rather than building per-platform integrations.
**Sources:** [Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation) · [Simon Willison](https://simonwillison.net/2026/Oct/22/donating-agent-skills/)

## 🔬 Research & Papers

### Ai2's OlmoEarth v1.3 gives every 10 m pixel a 128-number embedding
The open model turns a year of Sentinel and Landsat satellite imagery into a vector per 10-metre pixel, which downstream tools can use for land-cover and similar analysis. Across 27 tasks it scored highest on 20 against AlphaEarth Foundations and Tessera v2 (Ai2's own evaluation). The final training run cost about $2,720 of rented H100 time.
**Why it matters (PM):** Earth-observation features (risk, agriculture, logistics) become buildable from open embeddings rather than a proprietary data contract.
**Sources:** [Hugging Face / Ai2](https://huggingface.co/blog/allenai/olmoearth-v1-3)

## ⚖️ Policy, Safety & Regulation

### PHP patches two remote-code-execution flaws a day early after a disclosure leak
The PHP project shipped fixes across 8.x on 21 Oct after the CVE IDs circulated on 20 Oct with an inflated CVSS score of 10.0 (actual 9.2), and a security firm accidentally published a proof-of-concept exploit video. Wiz says it found the first flaw using AI tools, including Gemini 4 Argon and GPT-5.6 Sol, and confirmed unauthenticated remote code execution against Drupal and WordPress, both PHP-based.
**Why it matters (PM):** AI-assisted vulnerability discovery compresses the time between a bug being found and exploited, so dependency-patching SLAs for PHP-based components belong on this week's roadmap.
**Why it matters (mid-market):** Mid-sized firms running WordPress or Drupal-based sites and portals should confirm patching today, as exploit code is already circulating.
**Sources:** [Simon Willison](https://simonwillison.net/2026/Oct/21/php-security-release/)
