## 🛠️ Product Practice

### Simon Willison: "We're going to need default hard budget caps on pretty much everything"
Willison argues that coding agents make it easy to deploy pay-per-use services that can generate surprise bills, so hard caps (with an explicit opt-out) should be the default rather than soft warnings. He points to AWS's new project spend limits, which pause a project at the cap, and Google Cloud's Spend Caps launched in July.
**Why it matters (PM):** Ship hard spend limits as the default for any usage-priced or agent-driven feature; customers would rather hit an error than a surprise bill.
**Sources:** [Simon Willison](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/) · [Help Net Security on AWS](https://helpnetsecurity.com/2026/09/17/aws-spend-limit-agent-set-permissions)
