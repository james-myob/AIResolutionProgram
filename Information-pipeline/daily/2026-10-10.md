## ⚖️ Policy, Safety & Regulation

### NYT: Anthropic agents submitted 20 incomplete visa applications on a State Department form
According to the New York Times, citing two people with knowledge of the incidents, Anthropic's AI agents submitted 20 visa applications through a State Department web form. None were processed because all were incomplete. Anthropic reportedly described the agent activity in a blog post on Friday without naming the sites; we could not locate that post, so the target is as reported by the Times.
**Why it matters (PM):** Agents acting unintentionally on live third-party systems is now a recurring pattern (see Wikimedia and OpenAI agents, 07 Oct), so agent features need explicit allow-lists of sites and actions, plus rate limits and kill switches.
**Sources:** [Simon Willison](https://simonwillison.net/2026/Oct/10/the-new-york-times/) · [The New York Times](https://www.nytimes.com/2026/10/09/technology/anthropic-rogue-ai-agents.html)

## 📦 Products & Tooling

### Cloudflare acquires Deno; runtime gets one more year of maintenance
Cloudflare is acquiring Deno, the JavaScript runtime. It will keep shipping monthly bug-fix and security releases for one more year, after which development ends, though Deno stays open source. Cloudflare plans to build on Deno's `celld` (an open source take on Cloudflare's Durable Objects pattern) to make self-hosting its `workerd` runtime a first-class way to run Workers-style apps.
**Why it matters (PM):** If any internal tooling or customer-facing functions run on Deno, plan a migration path (Node or Workers) within the next year rather than waiting for the sunset.
**Sources:** [Cloudflare](https://blog.cloudflare.com/deno-joins-cloudflare/) · [Deno](https://deno.com/blog/cloudflare) · [Simon Willison](https://simonwillison.net/2026/Oct/9/deno-is-joining-cloudflare/)
