## 🧠 Models & Capabilities

### Z.ai ships GLM-5.4, its first "looped transformer"
GLM-5.4 reuses a group of middle layers several times per token, so the network is effectively deeper without more parameters. Per Latent Space's summary of Z.ai's post it is 750B parameters with 28 layers run twice, and Z.ai claims "2T–3T-class" performance; no benchmarks are published and the weights are not yet open. Access is currently via Z.ai's Coding Plan subscription, not the regular API.
**Why it matters (PM):** Two labs (Z.ai and Thinking Machines' Inkling 2 Mini) now use this design, so expect "more thinking per parameter" to show up as a cost lever; wait for independent benchmarks before changing any model-selection assumptions.
**Sources:** [Simon Willison](https://simonwillison.net/2026/Nov/23/glm-54/) · [Z.ai](https://z.ai/blog/glm-5.4) · [Latent Space](https://latent.space/p/ainews-jensen-is-back-and-openai-shows-its-pretraining-curve-joined-by-microsoft/)

## 📦 Products & Tooling

### Anthropic opens Claude Ship beta in Claude Code
Running `/ship` in Claude Code opens a pull request, reviews it, and works through feedback and failing checks; branch rules and permissions still govern merges. Anthropic also put zero data retention with Enterprise Frontier Safeguards into public beta.
**Why it matters (PM):** Review-and-fix is moving from a human step into the coding agent itself, so revisit how your team's merge rules and code-owner policies assume a human reviewer.
**Sources:** [ZDNet](https://www.zdnet.com/innovation/claude-ship-code-how-to-try/) · [Latent Space](https://latent.space/p/ainews-jensen-is-back-and-openai-shows-its-pretraining-curve-joined-by-microsoft/)
**Tags:** `entity:anthropic` `entity:claude-code` `theme:coding-agents` `tier:aggregator`

### OpenAI and Cisco release Shirudo, open-source "shields" for unpatched Linux systems
Shirudo uses eBPF (small programs that run inside the Linux kernel) to apply signed, temporary protections that block the code paths an exploit relies on, without restarting the service. In a controlled test a shield generated with Codex blocked a Java4Shell exploit against a running Elasticsearch instance. Code is on GitHub under BSD 2-Clause.
**Why it matters (PM):** Agent-written, human-approved mitigations shorten the window between a vulnerability and a patch; if you ship software customers self-host, this changes what "time to mitigate" can mean.
**Sources:** [OpenAI](https://openai.com/index/introducing-shirudo/) · [The Neuron](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-24-2026/)

## 🔬 Research & Papers

### DeepMind's Gemini 4 agents find cheaper quantum algorithms, verified in Lean
Teams of Gemini 4 agents cut the estimated cost of a fusion-energy calculation by 11.8x (5,650 to 4,338 error-corrected qubits), made a light-sensitive molecule simulation about 8x cheaper, and sped up Grover's algorithm 2.57x. Every result was proven correct in the Lean theorem prover, and the Lean library and verified solutions are open-sourced. These are DeepMind's own estimates, not hardware runs.
**Why it matters (PM):** Pairing agents with a machine checker for correctness is a reusable pattern: wherever your product can define "verified", autonomous work becomes far easier to trust.
**Sources:** [Google DeepMind](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/) · [The Neuron](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-24-2026/)
**Tags:** `entity:google-deepmind` `theme:agents` `theme:formal-verification` `tier:lab-official`

### OpenAI: GPT-6 models can design proteins, with modest lab hit rates
OpenAI says GPT-6 models design protein shapes and sequences mainly through reasoning and code, matching or beating specialist models on many computational tasks. With partner Onava, 35 of 322 designed minibinders (10.9%) bound their targets and 14 of 107 GPT-6.2-sequenced proteins (13.1%) showed binding. OpenAI concedes structure prediction remains far weaker than specialist tools and its pipeline still used specialist models for filtering.
**Why it matters (PM):** General models are entering domain science without bespoke training, but the honest hit rates show a human-and-specialist loop is still required, so scope "AI for science" features as assisted workflows, not autonomous ones.
**Sources:** [OpenAI](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)

## 📈 Industry Analysis

### Microsoft joins OpenAI's shared perplexity metric (update to 22 Nov)
Microsoft AI, with OpenAI's permission, ran its MAI-2 Base on OpenAI's held-out eval and reported 0.819 log-perplexity (lower is better); Mustafa Suleyman cosigned the proposal and suggested bits-per-byte as a fairer cross-lab measure. **Why it matters (PM):** If a common progress measure emerges it will anchor "common limits" policy talk, so track which labs sign before treating it as an industry standard.

## 📒 New Concepts

### Looped transformer
**Plain English:** A model design where the same group of layers is run several times on each token, refining its internal state on each pass, instead of stacking many different layers. It buys "deeper" thinking without adding parameters, trading a bit more compute per token for a smaller model. Z.ai's GLM-5.4 and Thinking Machines' Inkling 2 Mini both use it.
**Origin:** [Simon Willison on GLM-5.4](https://simonwillison.net/2026/Nov/23/glm-54/)
**Tag:** `concept:looped-transformer`
