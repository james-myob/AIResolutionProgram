### Willison builds a blog feature by voice while cooking, via Codex voice mode
Simon Willison made a new Newsletters index page for his blog, importing his weekly and monthly newsletters with archive pages and search integration, almost entirely by talking to a coding agent through the ChatGPT desktop app's Codex voice mode. He reviewed the resulting pull request by typing, swapping one Git-based import for an API-based one. His conclusion: voice works well for multitasking, but typing is more efficient for details such as pasting code and error messages.
**Why it matters (PM):** A practitioner's account that hands-free agent sessions are viable for scoped feature work, so it's worth testing voice input as a mode in any agent or coding-assistant feature you're scoping, with typed fallback for precision tasks.
