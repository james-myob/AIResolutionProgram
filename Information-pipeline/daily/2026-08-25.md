## 🧠 Models & Capabilities

### DeepSeek ships an experimental multimodal model, narrowing the gap with Claude Opus 4.8
DeepSeek released V4-Flash-Vision-Exp, an experimental vision-capable variant of V4-Flash, on its API platform. It keeps V4-Flash's text, agentic, and reasoning performance while adding image understanding, and on multimodal agent benchmarks it closes much of the gap to Claude Opus 4.8. DeepSeek shipped a matching Harness 0.1.1 update the same day for out-of-the-box support.

**Why it matters (PM):** If your cost model for a vision-in-the-loop feature assumes only frontier labs can do multimodal agent work cheaply, re-check it — the open-weight tier is now close enough on benchmarks that a cheaper fallback model may be viable for non-critical paths.
**Sources:** [DeepSeek API Docs](https://api-docs.deepseek.com/news/news260821/) · [The Next Web](https://thenextweb.com/news/deepseek-v4-flash-vision-exp-opus-benchmarks) · [OfficeChai](https://officechai.com/ai/deepseek-releases-v4-flash-vision-exp-matches-opus-4-8-on-some-multimodal-benchmarks/)

## 📦 Products & Tooling

### Anthropic launches Claude Academy, a free training hub with 355 resources
Anthropic opened Claude Academy (academy.claude.com) on 20 August: free courses covering Claude.ai, Cowork, Claude Code, Claude Tag, and the API, built around a "4D" framework (Delegation, Description, Discernment, Diligence). Signed-in users can track progress and earn LinkedIn-shareable completion badges; content is available in multiple languages.

**Why it matters (PM):** A free, structured onboarding path from the model vendor itself changes the calculus for internal AI-adoption programs — before commissioning custom training material, check whether Academy content already covers it.
**Why it matters (mid-market):** Smaller teams without an L&D budget for AI tooling now have a no-cost, badge-backed training path — expect it to become the default onboarding link in mid-market Claude rollouts rather than a bespoke deck.
**Sources:** [Claude Academy](https://academy.claude.com) · [Superhuman AI](https://www.superhuman.ai/p/anthropic-launches-the-claude-academy-with-355-resources) · [EdTech Innovation Hub](https://www.edtechinnovationhub.com/news/anthropic-opens-claude-academy-with-free-ai-courses-and-workplace-rollout-guides)
**Tags:** `entity:anthropic` `entity:claude-academy` `theme:enterprise` `theme:packaging` `lens:mid-market`

### OpenAI brings GPT-5.6 into Kiro; reinstates the 5-hour cap on ChatGPT Work and Codex for Plus
OpenAI added its GPT-5.6 family (Sol/Terra/Luna) to Kiro, a third-party AI coding agent, pitching better performance-per-dollar for plan/build/review/test workflows. Separately, OpenAI confirmed it is restoring, from 25 August, the 5-hour rolling usage cap on ChatGPT Work and Codex for Plus ($20/mo) subscribers — a restriction it had lifted in mid-July. Pro ($100/$200) tiers keep running against weekly limits only, without the 5-hour ceiling.

**Why it matters (PM):** If you scoped a Plus-tier agentic workflow (long Codex sessions, ChatGPT Work multi-step tasks) during the six weeks the cap was off, it now needs to fit inside 5-hour windows again — budget the Pro tier for anything that doesn't.
**Why it matters (mid-market):** Plus is the tier most SMB and mid-market teams default to for "just use ChatGPT" workflows; the cap's return is a live example of vendor-side capacity constraints reshaping what a mid-market AI budget can actually assume week to week.
**Sources:** [OpenAI](https://openai.com/index/gpt-5-6-in-kiro/) · [9to5Mac](https://9to5mac.com/2026/08/24/openai-restores-5-hour-codex-and-work-limits-for-chatgpt-plus-users/) · [Korben](https://korben.info/en/openai-brings-back-5-hour-limit-codex.html)

## 🛠️ Product Practice

### Google Cloud: agent security is the top blocker to scaling agentic AI, recommends human-in-the-loop by design
Google Cloud's second annual State of AI Infrastructure report, drawing on 1,402 global IT leaders, found 4 in 5 organizations cite security, governance, or MLOps as their biggest blocker to production agentic AI, and 83% say they need infrastructure upgrades to run agents at scale. It recommends platform-level governance, task-level provenance, dynamic permissions, and human-in-the-loop checkpoints rather than bolting agent access onto legacy systems.
**Why it matters (PM):** This is a vendor survey, not independent research, but the specific blockers named (audit trails, dynamic permissions, escalation points) are a usable checklist before you scope any feature that gives an agent write-access to production systems.
**Sources:** [Google Cloud Blog](https://cloud.google.com/blog/topics/ai-infrastructure/state-of-ai-infrastructure-report-and-the-agentic-data-cloud)
