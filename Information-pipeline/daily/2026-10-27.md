## 🧠 Models & Capabilities

### OpenAI ships GPT-6.1 Terra, a cheaper midrange model for vision and computer use
OpenAI released GPT-6.1 Terra on 26 October, pitched at everyday work such as drafting proposals, reading technical drawings, filling in forms and editing video. Per Simon Willison, pricing is $1 input / $5 output per million tokens, about half GPT-5.6 Terra and GPT-6.1 Sol and about 10x GPT-6 Luna. He reports vision and computer use comparable to Sol but faster, and weaker than the top models elsewhere; performance claims come from OpenAI and early testers.
**Why it matters (PM):** A faster, cheaper tier that is close to the top model on computer use changes the cost-per-task maths for agent features, so re-run any unit-economics estimate that assumed Sol-level pricing.
**Why it matters (mid-market):** Lower per-task cost makes workflow automation (forms, proposals, document review) viable at mid-market price points that Sol-class models did not support.
**Sources:** [Simon Willison](https://simonwillison.net/2026/Oct/26/gpt-61-terra/) · [Latent Space](https://www.latent.space/p/ainews-anthropic-s1)

## 📦 Products & Tooling

### Anthropic explains how Claude Managed Agents separates the "brain" from the "hands"
In a long Latent Space interview about Opus 5.5 and the Claude Platform, Anthropic describes Claude Managed Agents: developers define an agent and start sessions without running their own infrastructure. The durable harness and session state (the "brain") are kept apart from the sandboxes that execute code (the "hands"), so a failed sandbox does not end the agent, and credentials sit in a separate vault injected via a proxy rather than inside the sandbox. I read only the first part of the transcript.
**Why it matters (PM):** The design shows the pattern customers will expect from agent features: recoverable sessions and credentials the generated code never sees, which is worth borrowing in your own security and reliability requirements.
**Sources:** [Latent Space](https://www.latent.space/p/opus55)

## 🔬 Research & Papers

### Anthropic reports early results from using Claude in drug development
Anthropic's life sciences team is working with six partners (BigHat Biosciences, Bristol Myers Squibb, Divergence Labs, Enveda, Generate Biomedicines, The Column Group) and its own programmes. Reported results include Enveda's Claude-based document review catching all 11 known manufacturing issues plus seven more and cutting human review time by 89%, and BigHat testing about 1,010 Claude-assisted variants with leads binding more than 10x tighter. Anthropic stresses the work is early and mostly preclinical; figures are partner- and company-reported.
**Why it matters (PM):** A regulated, document-heavy vertical with measured review-time savings is a template for how to scope and evidence an AI feature for a specific industry.
**Sources:** [Anthropic](https://www.anthropic.com/research/early-progress-drug-development)
