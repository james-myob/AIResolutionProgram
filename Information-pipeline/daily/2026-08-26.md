## 🧠 Models & Capabilities

### IBM ships Granite 4.2, open-weight enterprise models with native reasoning and agentic RL
IBM released Granite 4.2 on 25 August: fully open (Apache 2.0) models at 3B/8B/30B, trained on ~15T tokens with context windows up to 512K, and a thinking/non-thinking toggle to control compute per task. The 8B and 30B variants add "agentic RL" training — practicing tool use, code execution, and web search inside real sandbox environments before release.

**Why it matters (PM):** A no-licensing-gate model family with built-in tool-use and a compute dial is a credible default for on-prem or local-deployment features — worth a bake-off against whatever small model you're currently defaulting to.
**Sources:** [IBM Research](https://research.ibm.com/blog/introducing-granite-4-2) · [The Decoder](https://the-decoder.com/ibm-drops-open-weight-granite-4-2-family-with-built-in-agentic-capabilities-under-apache-2-0/) · [MarkTechPost](https://www.marktechpost.com/2026/08/25/ibm-releases-granite-4-2-bringing-native-reasoning-and-agentic-rl-to-open-enterprise-models/)

## 📦 Products & Tooling

### OpenAI's first Jalapeño results: 1.5-4x gains over Nvidia's GB200/GB300
OpenAI published first benchmarks for Jalapeño, its own inference chip: 1.5-1.9x higher throughput per kilowatt and 1.7-3.6x lower latency than Nvidia's GB200/GB300 racks, rising to 2.1-4.1x faster on the low-latency, conversational traffic ChatGPT actually generates. OpenAI plans to deploy it inside its own infrastructure by year-end, with a second generation already in development.

**Why it matters (PM):** If these numbers hold under independent scrutiny, watch whether the gains surface in API pricing or stay an internal OpenAI margin story before you revise any cost model built on Nvidia-rack economics.
**Sources:** [OpenAI](https://openai.com/index/jalapeno-first-results/) · [CNBC](https://www.cnbc.com/2026/08/26/openai-jalapeno-ai-chip-nvidia.html) · [TrendForce](https://www.trendforce.com/news/2026/08/26/news-openai-debuts-jalapeno-ai-inference-chip-with-samsung-reportedly-supplying-hbm4/)
**Tags:** `entity:openai` `entity:jalapeno` `entity:nvidia` `theme:compute` `theme:pricing`

### Anthropic unifies Claude's memory across Chat and Cowork, on by default
Context now persists both ways: what Claude remembers from a chat is available when Cowork runs a cloud task, and what Cowork learns carries back into Chat. A new settings view lists everything stored as editable files/topics; sensitive topics (health, beliefs) stay off by default, and SSNs, criminal history, and immigration status are never stored regardless of settings. Live now on Free, Pro, and Max.

**Why it matters (PM):** The hard-excluded data categories and editable-memory UI are a usable reference point if you're scoping your own memory/personalization feature and need a defensible default for what never gets saved.
**Why it matters (mid-market):** Small teams running quick chats alongside longer Cowork tasks no longer have to duplicate context between them — a real quality-of-life gain for a segment less likely to have custom tooling stitching the two together.
**Sources:** [9to5Mac](https://9to5mac.com/2026/08/25/anthropic-update-unifies-memory-feature-across-claude-cowork-and-chat/) · [Engadget](https://www.engadget.com/2243753/claude-memory-now-works-across-both-chats-and-cowork-sessions/) · [The Next Web](https://thenextweb.com/news/anthropic-claude-cowork-shared-memory-default)
**Tags:** `entity:anthropic` `theme:memory` `theme:enterprise` `lens:mid-market`

### Thomson Reuters launches Thomson, a proprietary legal LLM built on Westlaw and Practical Law
Thomson Reuters spent ~$40M specializing an open-source base model (most recently Qwen 3.5) into "Thomson" — pretrained on Westlaw, Practical Law, and Checkpoint content, then post-trained with legal professionals and RL for tool use inside its own products. It now powers the next generation of CoCounsel Legal, at a fraction of frontier-model training cost.

**Why it matters (PM):** A content-rich incumbent building a cheap, narrow, fully-owned specialist model on an open-source base — instead of wrapping a frontier API — is a template worth studying if your company sits on a large proprietary corpus.
**Sources:** [Thomson Reuters](https://www.thomsonreuters.com/en/press-releases/2026/august/thomson-reuters-leverages-its-world-class-data-assets-to-launch-its-own-frontier-model) · [LawNext](https://www.lawnext.com/2026/08/thomson-reuters-launches-thomson-its-own-proprietary-llm-trained-on-westlaw-and-practical-law-content.html) · [SiliconANGLE](https://siliconangle.com/2026/08/24/thomson-reuters-launches-proprietary-ai-model-for-legal-work/)

## 📈 Industry Analysis

### Amazon shuts down Mechanical Turk after 21 years as AI training-data work moves to specialized platforms
Amazon will close Mechanical Turk — the crowdsourced task marketplace Jeff Bezos once called "artificial artificial intelligence" — on 30 September, following an internal assessment. Launched in 2005 and once serving 500,000+ workers, it had been in decline as data-labeling specialists like Scale AI, Mercor, and Prolific drew away the AI-training workload it used to host.

**Why it matters (PM):** If any part of your eval or fine-tuning pipeline still quietly depends on MTurk for human labeling or preference data, that dependency now has a hard deadline — and the specialist platforms that replaced it are a better default anyway.
**Sources:** [CNBC](https://www.cnbc.com/2026/08/25/amazon-service-that-jeff-bezos-called-artificial-ai-is-shutting-down.html) · [Tech Startups](https://techstartups.com/2026/08/26/amazon-is-shutting-down-mechanical-turk-after-21-years-as-ai-reshapes-crowdsourced-work/)
