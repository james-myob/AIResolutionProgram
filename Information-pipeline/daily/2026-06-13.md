## 🧠 Models & Capabilities

### Anthropic releases Claude Fable 5 — first publicly accessible Mythos-class model

On June 9, Anthropic released Claude Fable 5, the first model in a new Mythos-class tier that sits above the Opus line in capability. Fable 5 is immediately available via the Claude API and Amazon Bedrock, and is included free for Claude Pro, Max, Team, and Enterprise users through June 22. A companion model, Claude Mythos 5, is the same base model with safety guardrails lifted, available only to vetted infrastructure providers and cybersecurity researchers via Project Glasswing; in high-risk domains (cybersecurity, biology, chemistry), Fable 5 itself blocks responses and falls back to Opus 4.8. Pricing: $10/M input tokens, $50/M output — the most expensive widely available Anthropic model, but less than half the price of Mythos Preview.

**Why it matters (PM):** Fable 5 is state-of-the-art across software engineering, vision, knowledge work, and scientific reasoning per Anthropic's benchmarks — any roadmap item you've categorised as "not achievable with current models" deserves a reassessment before your next planning cycle.

### Google DeepMind ships DiffusionGemma — 4× faster open model using text diffusion

Google DeepMind released DiffusionGemma on June 10, an experimental 26B mixture-of-experts open-weights model (3.8B parameters active per step) that generates text through discrete diffusion rather than token-by-token autoregression — it starts from a canvas of noise tokens and denoises 256 tokens in parallel per pass. The model achieves 1,000+ tokens/second on a single H100 GPU and ships under Apache 2.0; quality trade-off: lower benchmark scores than standard Gemma 4 on MMLU and coding, positioning it as experimental for speed-critical workflows.

**Why it matters (PM):** Latency is the constraint that separates AI-powered UX that feels instant from UX that feels lagged. A 4× throughput uplift at open-source pricing could make real-time AI experiences (streaming document editing, live transcription processing) economically viable at scales that were previously out of reach.

## 📒 New Concepts

### Text Diffusion Inference
**Plain English:** A method of generating text by starting with a sequence of random "noise" tokens and iteratively refining all of them in parallel — the opposite of how GPT-style models work, which write text one token at a time left to right. Because all tokens are updated simultaneously in each pass, the model can produce 256+ tokens per step rather than one, yielding 4× or higher throughput on the same hardware. The quality trade-off is real: current text-diffusion models score lower than autoregressive models on knowledge and coding benchmarks, but they win on raw output speed. DiffusionGemma is the first major-lab production release of this approach. Expect to hear "text diffusion" in infrastructure and platform pitches this quarter as vendors position it against standard inference pricing.
**Origin:** [Google DeepMind — DiffusionGemma](https://deepmind.google/models/gemma/diffusiongemma/)
