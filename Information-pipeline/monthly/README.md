# Monthly Trend Packs

Generated on the last weekday of each calendar month from that month's daily and weekly briefings. Each month produces:

- **`YYYY-MM.md`** — the Markdown trend pack (auto-generated via Claude API).
- **`decks/YYYY-MM.pptx`** — the 8-12 slide presentation deck, exported from [claude.ai/design](https://claude.ai/design) after pasting the Markdown.

See [`../workflow.md`](../workflow.md) §"Monthly run" for the step-by-step.
