# Weekend 2 Project: The Model Mapping Project
## BUILD YOUR PERSONAL AI TOPOGRAPHY

**The Deliverable:** Model Topography Sheet + "AI Rules of Thumb" document.

## The Work

- **Pick 2-3 Models:** Use what you have (Claude, ChatGPT, Gemini).
- **Run Tests:** Run the same task through each: Deep Research, Writing, Strategy, Data, Visual.
- **Compare:** Which felt right? Which was faster? Which asked better questions?
- **Synthesize:** Create a one-page "Rules of Thumb" (e.g., "Claude for drafts, ChatGPT for code").

## Advanced

- Test specialized tools (Perplexity, etc.).
- Build a matrix including cost & context window.
- Test output consistency over time.
- Track "editing time" needed per model.

## Why It Matters

Most people default to one AI model for everything, leaving capability on the table. The goal isn't "which model is objectively best" — it's developing your own instincts for which interface and brain works best for your specific tasks.

## Done When

You can answer "which tool do I use for what?" in 30 seconds without hesitation.
