# Bonus Weekend: The Agent Exploration
## RUN THE AGENT EVALUATION GAUNTLET

**Deliverable:** Agent Scorecard + Use Cases

## Mission Briefing

Design a comprehensive evaluation framework for AI agents. Test autonomous AI systems on real-world tasks, measure their capabilities, and document your findings for the community.

## The Gauntlet Tasks

1. **Research + Synthesis** — Process 8 links/docs into a brief. Identify missing info.
2. **Operations Task** — Turn notes into a checklist with timeline & roles.
3. **Production Task** — Generate summary, email, 5 posts, & overview.

## Tips & Tactics

1. Define clear evaluation criteria
2. Create reproducible test scenarios
3. Compare multiple agent frameworks
4. Share your methodology and results
